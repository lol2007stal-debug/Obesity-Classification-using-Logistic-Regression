# Проект посвящён задаче классификации уровня ожирения на основе данных о пищевых привычках и физическом состоянии человека.
Используется датасет, содержащий информацию о жителях Мексики, Перу и Колумбии.

Модель логистической регрессии применяется для прогнозирования степени ожирения на основе демографических, поведенческих и наследственных факторов.
Источник данных: Estimation of Obesity Levels Based on Eating Habits and Physical Condition UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/544/estimation+of+obesity+levels+based+on+eating+habits+and+physical+condition
